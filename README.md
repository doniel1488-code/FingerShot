# FingerShot

FingerShot — способность для Minecraft Java Edition **1.21.8** на Fabric. Игрок заряжает палец и выпускает фиолетовую сферу с энергетическим шлейфом. Импульс прорезает сквозной тоннель и поражает сущностей по всей траектории.

## Установка и управление

1. Установите Java 21, Fabric Loader 0.18.4 или новее и Fabric API для Minecraft 1.21.8.
2. Скачайте артефакт `fingershot-fabric` из [сборки в GitHub Actions](https://github.com/doniel1488-code/FingerShot/actions/workflows/build.yml). Поместите JAR из архива в папку `mods`.
3. Для LAN установите мод и Fabric API у хозяина мира и участников. Для выделенного сервера установите оба JAR на сервер и на клиенты, которым нужна способность и её эффекты. Клиент и сервер должны использовать одну версию FingerShot.
4. Удерживайте **R** для зарядки. Отпустите после прохождения отметки на индикаторе, чтобы выстрелить. Полный заряд повышает урон и силу отбрасывания. Можно изменить клавишу в настройках управления.

Короткое нажатие сбрасывает зарядку. При открытии меню и начале использования предмета зарядка прерывается. После выстрела индикатор показывает время до готовности способности.

## Разрезание блоков

Сервер прорезает тоннель радиусом до 1,65 блока и длиной до 128 блоков по умолчанию. Луч проходит через камень, обсидиан, постройки и другие разрушаемые блоки. Каждая подходящая сущность в тоннеле получает одно попадание. Урон и радиус растут с зарядом.

Бедрок, контейнеры и защищённые блоки сохраняются. Когда такой блок оказывается на оси выстрела, импульс останавливается. Границы мира и защита территорий проверяются на сервере. Луч проходит через жидкости и обрабатывает только загруженные чанки. Дроп зависит от режима игры, инструмента и чар по ванильным правилам.

Для части рассечённых блоков клиент показывает светящийся срез и две половинки исходной модели. Для сложных моделей остаётся фиолетовый шлейф. Количество обломков ограничено, а сервер выполняет не более 8192 разрушений за выстрел.

## Настройки

Файлы создаются в папке `config` при запуске. Перезапустите сервер или клиент после правок. При обновлении с 0.1.0 старые значения по умолчанию для дальности, урона и отбрасывания повышаются автоматически. Чтобы закрепить собственные значения, задайте `format: 2` в серверном JSON. Значения вне допустимого диапазона ограничиваются, повреждённый JSON приводит к загрузке настроек по умолчанию.

| Файл | Поле | По умолчанию | Значение |
| --- | --- | --- | --- |
| `fingershot.json` | `range` | 128 | Дальность луча в блоках (2–256) |
| | `radius` | 1.65 | Радиус тоннеля при полном заряде (0,65–3 блока) |
| | `chargeTicks` | 24 | Тики до полной зарядки |
| | `cooldownTicks` | 32 | Тики восстановления после выстрела |
| | `damage` | 64 | Урон полного заряда в очках здоровья |
| | `knockback` | 2.3 | Сила отбрасывания от полного заряда |
| | `affectEntities` | true | Попадания по сущностям |
| | `sliceBlocks` | true | Разрезание блоков |
| | `volume` | 0.75 | Общий множитель громкости, передаваемый клиентам |
| `fingershot-client.json` | `maxFragments` | 24 | Лимит одновременно видимых половинок |
| | `effects` | 1 | Интенсивность луча и частиц от 0 до 2 |
| | `volume` | 0.75 | Локальный множитель громкости |

## Сборка

Запустите `./gradlew build` на Linux/macOS или `gradlew.bat build` на Windows с Java 21. Результат находится в `build/libs/fingershot-0.2.0.jar`. Тесты покрывают клиппинг полигонов, UV и цвет на срезе, границы заряда и перезарядки, а также повторную отправку намерения выстрела.

Звуки синтезированы для FingerShot и входят в проект под лицензией MIT.

Сборка запускает также серверные игровые тесты Fabric для попаданий, защиты контейнеров и дропа. В GitHub Actions после сборки JAR запускается клиентский сценарий зарядки и выстрела с записью снимков игры.
