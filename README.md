# FingerShot

FingerShot — способность для Minecraft Java Edition **1.21.8** на Fabric. Игрок заряжает палец, направляет руку на цель и выпускает энергетический луч. У подходящих блоков становятся видны движущиеся половинки исходной модели со светящимся срезом.

## Установка и управление

1. Установите Java 21, Fabric Loader 0.18.4 или новее и Fabric API для Minecraft 1.21.8.
2. Скачайте артефакт `fingershot-fabric` из [сборки в GitHub Actions](https://github.com/doniel1488-code/FingerShot/actions/workflows/build.yml). Поместите JAR из архива в папку `mods`.
3. Для LAN установите мод и Fabric API у хозяина мира и участников. Для выделенного сервера установите оба JAR на сервер и на клиенты, которым нужна способность и её эффекты.
4. Удерживайте **R** для зарядки. Отпустите после прохождения отметки на индикаторе, чтобы выстрелить. Полный заряд повышает урон и силу отбрасывания. Можно изменить клавишу в настройках управления.

Короткое нажатие сбрасывает зарядку. При открытии меню и начале использования предмета зарядка прерывается. После выстрела индикатор показывает время до готовности способности.

## Разрезание блоков

Сервер вычисляет направление и попадание по положению и взгляду игрока. Препятствие останавливает луч, а подходящая сущность перед препятствием получает одно попадание. Для блоков мод использует стандартный серверный путь разрушения, включая проверки режима игры, спавна и события Fabric для защиты территорий. Дроп подчиняется ванильным правилам инструмента, чар и режима игры. Например, для булыжника в режиме выживания понадобится подходящая кирка.

Клиент делит полигоны запечённой модели плоскостью, интерполирует UV и цвет вершин и замыкает обе части светящейся поверхностью. Поддерживаются компактные полные кубы из тега `fingershot:sliceable`, включая камень, булыжник, землю, обычные доски и брёвна. Ступени, жидкости, контейнеры и прочие неподходящие блоки получают только эффект попадания. Если ресурс-пак меняет модель поддерживаемого блока на сложную, клиент показывает эффект попадания без геометрических половинок. Решение об удалении такого блока по-прежнему принимает сервер по тегу и состоянию блока. Половинки существуют только как временная клиентская геометрия.

## Настройки

Файлы создаются в папке `config` при запуске. Перезапустите сервер или клиент после правок. Значения вне допустимого диапазона ограничиваются, повреждённый JSON приводит к загрузке настроек по умолчанию.

| Файл | Поле | По умолчанию | Значение |
| --- | --- | --- | --- |
| `fingershot.json` | `range` | 30 | Дальность луча в блоках |
| | `chargeTicks` | 24 | Тики до полной зарядки |
| | `cooldownTicks` | 32 | Тики восстановления после выстрела |
| | `damage` | 12 | Урон полного заряда в очках здоровья |
| | `knockback` | 1.1 | Сила отбрасывания от полного заряда |
| | `affectEntities` | true | Попадания по сущностям |
| | `sliceBlocks` | true | Разрезание блоков |
| | `volume` | 0.75 | Общий множитель громкости, передаваемый клиентам |
| `fingershot-client.json` | `maxFragments` | 24 | Лимит одновременно видимых половинок |
| | `effects` | 1 | Интенсивность луча и частиц от 0 до 2 |
| | `volume` | 0.75 | Локальный множитель громкости |

## Сборка

Запустите `./gradlew build` на Linux/macOS или `gradlew.bat build` на Windows с Java 21. Результат находится в `build/libs/fingershot-0.1.0.jar`. Тесты покрывают клиппинг полигонов, UV и цвет на срезе, границы заряда и перезарядки, а также повторную отправку намерения выстрела.

Звуки синтезированы для FingerShot и входят в проект под лицензией MIT.

Сборка запускает также серверные игровые тесты Fabric для попаданий, защиты контейнеров и дропа. В GitHub Actions после сборки JAR запускается клиентский сценарий зарядки и выстрела с записью снимков игры.
